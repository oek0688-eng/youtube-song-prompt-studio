# YouTube Song Prompt Studio

YouTube 레퍼런스 영상을 재생하며 음악적 특징을 정리하고, 생성형 음악 도구에 넣을 프롬프트를 만드는 작은 웹 앱입니다.

## 시작하기
`index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치나 서버가 필요하지 않습니다.

## 현재 기능
- YouTube 영상 링크 여러 개 추가 및 임베드 재생
- 조회수 메모
- 장르, 분위기, 템포, 보컬, 사운드, 전개, 가사 주제 입력
- 입력한 특징을 바탕으로 오리지널 곡 생성 프롬프트 작성 및 복사

## 한계
현재 버전은 YouTube 오디오를 자동 분석하거나 조회수를 가져오지 않습니다. 사용자가 영상을 듣고 특징을 입력합니다. 자동 분석에는 별도 분석 서비스/API 연결이 필요합니다.
